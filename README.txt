# Bank Personal Loan Prediction - Streamlit App

**Live Demo:** [Bank Personal Loan Prediction App](https://bank-personal-loan-prediction-xjkx4ytn9swhwdmmsqxa9m.streamlit.app/)

## Files
- app.py
- logistic_regression_model.pkl
- random_forest_model.pkl
- feature_columns.pkl
- model_performance.csv
- best_model_name.pkl

## Run locally

Open Command Prompt / PowerShell in this folder and run:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the local Streamlit address shown in the terminal, normally:
http://localhost:8501

## Important
Do NOT run `app.py` as a normal Python cell in Google Colab.
Streamlit is designed to run as a web application from the terminal.
